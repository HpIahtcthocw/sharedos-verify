How It Works

One call.
Four fields. Done.

01

Send a claim

Call POST /verify with any assertion. Optionally include context or background material for more accurate analysis.

02

LLM evaluates with structured output

Veritas uses a specialized prompt + JSON Schema to extract a credibility score (0-100), verdict category, supporting evidence, and risk factors — all in ~10 seconds.

03

Get structured verdict

Receive a machine-readable response with credibility score, verdict (可信 / 存疑 / 不可信 / 无法判定), evidence list, and risk factors.

04

Every call is audited

All invocations are logged to a JSONL audit trail — transparent, verifiable, and visible to Arena judges. Your usage counts toward competition rankings.
